Python Data Visualization

A structured breakdown of Univariate, Bivariate, and Multivariate analysis using Pandas and Matplotlib.

01. Environment & Data Setup

Initialization

Before plotting any visual markers, we initialize the data frame infrastructure using Pandas.

  • Imports necessary libraries (`pandas` and `pyplot`).
  • Creates a multi-featured dataset containing Salary, Department, and Age dimensions.
  • Outputs dataframe structure metrics via `df.shape`.
Python Blueprint
import pandas as pd
import matplotlib.pyplot as plt

data = {
    "salary": [25000,30000,37000,28000,39000,48000,55000,52000,35000,26000,27000,31000,33000,29000,40000,36000,34000,45000,47000,50000],
    "dept": ["HR","IT","Finance","IT","HR","Finance","IT","HR","Finance","IT","HR","Finance","IT","HR","Finance","IT","HR","Finance","IT","HR"],
    "age": [22,25,30,28,35,40,45,32,38,27,29,31,33,26,37,42,24,36,39,41]
}

df = pd.DataFrame(data)
print(df)
print(df.shape)

02. Univariate Analysis: Line Plot

Univariate

Univariate plots focus on a single column to observe pattern sequences or trends.

  • color & marker: Customizes aesthetic clarity for individual data tracking nodes.
  • linestyle & linewidth: Adjusts connectivity styling options to enhance visual hierarchy.
Python Blueprint
# Line plot to observe index sequence variations
plt.plot(df["salary"], color='red', marker='o', 
         linestyle=':', linewidth=2, markersize=8)

plt.title("Salary Track Profile")
plt.show()

03. Univariate Analysis: Histogram

Univariate

Histograms display the frequency distribution of a continuous variable.

  • bins: Dictates the number of intervals/bars to bundle your metrics.
  • edgecolor: Separates layout boundaries to prevent bars from merging visually.
Python Blueprint
# Histogram visualization for value frequencies
plt.hist(df["salary"], color='blue', bins=5, edgecolor='black')

plt.xlabel("Salary Range")
plt.ylabel("Frequency")
plt.title("Salary Distribution Overview")
plt.show()

04. Box Plots & Outlier Tracking

Univariate

Box plots visually isolate mathematical anomalies (outliers) outside normal variance metrics.

  • Middle Line: Marks dataset Median value.
  • Box Boundaries: Represents the Interquartile Range (IQR) from Q1 to Q3.
  • Outliers: Values placed outside 1.5 times the IQR limits.
Python Blueprint
# Box plot tracking for outliers identification
plt.boxplot(df["salary"], vert=False)

plt.xlabel("Salary")
plt.title("Salary Distribution Outlier Boundaries")
plt.show()

05. Categorical Distribution: Pie Chart

Univariate

Categorical data relies on proportional splits. Pie charts illustrate share contributions efficiently.

  • Line tracking charts cannot process categorical inputs natively.
  • value_counts(): Computes categorical frequencies before visualization steps.
  • explode: Highlights custom focal segments away from core graph structure.
Python Blueprint
# Computing value balances
count = df["dept"].value_counts()

# Pie Chart production
plt.pie(count, labels=count.index, autopct='%1.1f%%', 
        explode=[0, 0.1, 0.2], colors=['red','blue','green'])

plt.title("Department Distribution Shares")
plt.show()

06. Categorical Distribution: Bar Chart

Univariate

Bar charts excel at highlighting absolute item volumes across categories side-by-side.

  • count.index: Forms X-axis categorization labels.
  • count.values: Explicitly drives physical bar elevations.
Python Blueprint
# Generating quantitative vertical bar comparative view
plt.bar(count.index, count.values, color=['red','blue','green'])

plt.xlabel("Department")    
plt.ylabel("Number of Employees")
plt.title("Department Allocation Count")
plt.show()

07. Bivariate Analysis: Scatter Plot

Bivariate

Bivariate analysis explores correlations and interactive behaviors between two features.

  • plt.scatter(): Maps two numeric ranges (Age vs. Salary) onto a coordinate space.
  • Helps highlight relational dependencies or cluster anomalies immediately.
Python Blueprint
# Scatter plot charting correlation pairs
plt.scatter(df["age"], df["salary"], color='blue')

plt.xlabel("Age")
plt.ylabel("Salary")
plt.title("Relationship between Age and Salary")
plt.show()

08. Ordered Relationship Trends

Bivariate

Standard data sequences often lead to erratic, unreadable lines when tracing bivariate relationships over chronological indicators like age.

  • sort_values(): Sorts features along the X-axis first to produce clean, readable trendlines.
Python Blueprint
# Sort values to organize independent axis sequencing
df_sorted = df.sort_values('age')

plt.plot(df_sorted["age"], df_sorted["salary"], color='red', 
         marker='o', linestyle='-', linewidth=2, markersize=8)

plt.xlabel("Age")
plt.ylabel("Salary")
plt.title("Trend of Salary over Age (Sorted)")
plt.show()

09. Multivariate Analysis: Grouped Box Plot

Multivariate

Multivariate visualizations analyze multiple features concurrently to evaluate comparative behavior patterns.

  • Filters numerical metrics (Salary) independently across distinct categorical channels (Departments).
  • Allows side-by-side distribution comparisons across multiple groups in a single view.
Python Blueprint
# Segregating subsets inside a matrix compilation list
plt.boxplot([
    df[df["dept"]=="HR"]["salary"],
    df[df["dept"]=="IT"]["salary"],
    df[df["dept"]=="Finance"]["salary"]
], labels=["HR","IT","Finance"])

plt.legend(["HR","IT","Finance"])
plt.xlabel("Department")
plt.ylabel("Salary")
box_title = "Distribution of Salary by Department"
plt.title(box_title)
plt.show()

10. Aggregated Multivariate Share Tracking

Multivariate

Using categorical values alongside structural data aggregations helps reveal broader organizational trends.

  • groupby(): Collapses observations into targeted category summaries.
  • Exposes average compensation variances across entire departments.
Python Blueprint
# Grouping and calculating sector averages
salary_by_dept = df.groupby("dept")["salary"].mean()
print(salary_by_dept)

# Pie chart execution over structured segment fields
plt.pie(salary_by_dept, labels=salary_by_dept.index, 
        autopct='%1.2f%%', colors=['red','blue','green'])

plt.title("Distribution of Average Salary by Department")
plt.show()
